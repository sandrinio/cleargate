## [0.31.0] — 2026-11-16

### Upgrade notes
- **If the configured test command cannot run in the repo, sprint preflight now stops.** An
  example is `make check` needing a database URL. Record the reason once: add
  `"test_waiver": "<reason>"` under `"qa"` in `.cleargate/scripts/gate-checks.json` and commit it.
  `cleargate upgrade` keeps it. Merges whose test stops the same way are then recorded
  `NOT TESTED`, and the sprint report names the waiver. Without a waiver those merges are refused.
- **Remove a `node_modules/cleargate` link you added only for `close_sprint.mjs`.** It is not
  needed. Close now finds the CLI behind `PATH` (BUG-114).
- **Kickoff assigns lanes itself.** `cleargate sprint init <id> --stories …` computes each
  item's lane. Do not re-run `init_sprint.mjs --force` after the design review.
- **Close finishes the sprint on your ack.** It commits the close artefacts, merges `sprint/S-NN`
  into `main` (from a Claude worktree session or a plain checkout), clears `.active` and prints a
  doc-refresh checklist at the Gate 4 prompt. Do no hand merge and no hand edit of `.active`.
- **`upgrade` prints less.** Files already equal to the package get no line. A file whose local
  edits are replaced says so. Read the printed `Upgrade notes` before the plan.
