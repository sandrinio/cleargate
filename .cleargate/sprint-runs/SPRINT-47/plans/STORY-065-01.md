## Predicate contract (Developer implements exactly)
All changes are in `src/lib/readiness-predicates.ts`:
- Exports: `PROOF_TIERS = ['unit','container','live','human'] as const`, `isProofTier(x: unknown): boolean` (exact string match, no trim) and `PROOF_DECLARED_CUTOVER: string`.
- The cut-over is a UTC ISO timestamp at second precision, ending in `Z`, set to the moment the Developer builds on the merge day. It must be later than every story/CR/bug `created_at` in OUTER `pending-sync`; the newest at plan time is `2026-11-16T07:39:06.618Z` (STORY-065-06).
- Add `{ kind: 'proof-declared' }` to `ParsedPredicate` (`:14-28`), parser branch `// 14.` before the throw (`:158`), and `case 'proof-declared': return evalProofDeclared(doc);` in `evaluate` (`:188-215`).
- The docstring at `:3` changes to `Supports exactly 15 closed-set predicate shapes.` The code count and the doc count differ by one on purpose: marker-absence is its own union member but is folded into doc shape 2 (`test-layers-declared-doctrine.red:354-357`).
- `evalProofDeclared` checks in this order and returns the first failure. Every detail starts with `proof-declared: `.
  0. Read `created_at`: a Date gives `getTime()`, anything else gives `Date.parse(String(v))`. If the value is finite and `< Date.parse(CUTOVER)`, pass with `pre-cutover (created_at <v>)`. A missing or unparseable value means the rule applies.
  1. `proof_tier` is absent, null or blank: fail with `proof_tier is missing — set unit, container, live or human (copy proof_tier and ## Proof from the item template)`.
  2. Not a valid tier: fail with `proof_tier "<v>" is not one of unit, container, live, human`.
  3. No `## Proof` heading outside a fence: fail with `## Proof section is missing (copy it from the item template)`.
  4. Expected result is empty: fail with `Expected result is empty or a {…} placeholder`.
  5. Tier `human` and Why human is empty: fail with `human tier needs a filled Why human`.
  6. Tier `live` with neither a command nor filled Steps: fail with `live tier needs a proof command block or filled Steps`.
  7. Tier `container` or `live` with no holdout scenario: fail with `<tier> tier needs at least one @holdout scenario`.
  8. Otherwise pass with `<tier> proof declared`.
- **Label value.** A label line starts with `- **<Label>:**` inside the Proof section and outside its fence. Its value is the rest of that line plus continuation lines: the lines that follow, up to the first blank line, column-0 `- ` line, fence or heading. A continuation line counts once a leading `-`, `*` or `\d+.` marker is stripped. The label is filled when any of these pieces passes `!isBlankOrPlaceholder` (`:1562`, reuse it).
- **Command.** The first non-blank line of the first fence under the heading, unless it is a whole `{…}` placeholder (that line then counts as no command). This is identical to P1.
- Reads `doc.fm` and `doc.body` only, with no fs access and no branch on work-item type.
