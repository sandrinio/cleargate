- **R11: new `judgeTestFailure` signature.** The third argument stays the seam object, so the sealed three-argument T9 calls keep their results.
  `export function judgeTestFailure(output, baseline, { extract = extractFailing, exitCode } = {}): { excused, ids, new_ids, reason }`
  `reason` ∈ `no-baseline | unparsed | new-failures | excused | baseline-unnamed`. Order:
  1. `ids = extract(output)`.
  2. `!baseline || !Array.isArray(baseline.failing)` → `no-baseline` (unchanged).
  3. `ids.length === 0` → `{ excused: true, ids: [], new_ids: [], reason: 'baseline-unnamed' }` only when all of these hold: `baseline.failing.length === 0`; `Number.isInteger(baseline.exit_code) && baseline.exit_code !== 0`; `exitCode === baseline.exit_code`; `lastLine(output) !== ''` and `lastLine(output) === lastLine(baseline.tail)`. Otherwise `unparsed` (unchanged).
  4. Some id not in `baseline.failing` → `new-failures`; else `excused` (unchanged). So a named failure against an unnamed baseline (`failing: []`) is `new-failures`.
  - `lastLine(x)` (internal): a string is split on `/\r?\n/`; an array has each element split the same way; each line is `.trim()`med; the result is the last non-empty line, or `''` when there is none or `x` is neither a string nor an array. **Normalisation is trim only**: no path, ANSI or timestamp stripping. Dispenser's guard (`Makefile:22: *** make check needs OWL_TEST_DATABASE_URL, … Stop.`) is a parse-time `$(error)` (dispenser `Makefile:20-24`): stderr only, path-free, and identical in the root and every worktree after a trim.
  - Baseline absent → `no-baseline`; `exit_code` 0 or missing → `unparsed`. In both cases every unnamed failure counts, as before. A baseline tail that ends in record_baseline's own `baseline: command timed out …` or spawn-error line (`record_baseline.mjs:111-127`) never matches.
