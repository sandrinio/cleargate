## Decisions (this plan governs; for the orchestrator to ratify as CR:spec-clarifications)

- **D-1 Count rule.** For each listed file, count `max(0, countTests(name, HEAD text) - countTests(name, base text))`. The base is `git merge-base <--sprint-branch> HEAD`, computed by `seal_red.mjs` once, right after the re-seal check.
  - The base is a commit SHA (40 hex). It goes into the scan env as `CLEARGATE_RED_BASE` only when `scenarios > 0` and `merge-base` exits 0. Otherwise the variable is deleted from the scan env, and the count is today's.
  - A file absent at the base counts in full. Deleting one inherited test while adding one nets 0 (OD-1, accepted).
- **D-2 One reader.** A new export in `qa_red_lint.mjs`, `readBaseText(dir, base, rel)`, runs
  `git -C <dir> show <base>:./<rel>`.
  - It strips `GIT_DIR`/`GIT_WORK_TREE`/`GIT_INDEX_FILE`, sets `maxBuffer` to 64 MiB, and returns `''` on any non-zero exit or spawn error.
  - `seal_red.mjs` imports it beside `countTests`/`countScenarios`. The import is static, so the Gate 4 re-sync copies the two files together.
- **D-3 Relative file list.** `seal_red.mjs` passes `CLEARGATE_RED_FILES` as the worktree-relative POSIX form of each argument: `path.relative(wt, path.resolve(wt, f))` with `\` mapped to `/`.
  - Relative arguments (every caller today) are byte-identical.
  - An absolute argument now reads its base correctly instead of counting in full.
  - `git add`/`git commit` still receive the arguments as given.
- **D-4 Flag text.** `rVolume`'s flag is unchanged: `R-volume: <T> tests for <S> scenarios (limit <2S>)`.
  - `main()` appends `; counted: tests added since <base.slice(0, 7)>` when `CLEARGATE_RED_BASE` is non-empty.

- **D-5 Seal JSON `tests`.** `seal_red.mjs` uses the same per-file delta when it has a base, and today's whole-file count otherwise. Every other JSON key, the seal line keys, and the exits are unchanged.
- **D-6 Runner backstop.** In the red branch, `lintOnly` holds when all of these are true:

3. Replace `rVolume` and its JSDoc (`:400-422`) with:
   ```js
   /**
    * Volume rule over an explicit list of files. A file with `baseText` counts only the tests it
    * gained over that text, floored at 0 (STORY-066-22); without it the whole file counts.
    * @param {{files: {name: string, text: string, baseText?: string}[], scenarios: number}} input
    * @returns {{tests: number, flag: string|null, uncounted: string[]}}
    */
   export function rVolume({ files, scenarios }) {
     let tests = 0;
     const uncounted = [];
     for (const f of files) {
       const ext = path.extname(f.name).toLowerCase();
       if (!COUNTED_EXT.includes(ext)) {
         uncounted.push(f.name);
         continue;
       }
       tests += Math.max(0, countTests(f.name, f.text) - countTests(f.name, f.baseText ?? ''));
     }
     const limit = 2 * scenarios;
     const flag =
       scenarios > 0 && tests > limit
         ? `R-volume: ${tests} tests for ${scenarios} scenarios (limit ${limit})`
         : null;
     return { tests, flag, uncounted };
   }

   /**
    * A listed file's text at commit `base` (STORY-066-22); '' when git fails or the file is absent there.
    * @param {string} dir worktree top
    * @param {string} base commit
    * @param {string} rel path relative to dir
    * @returns {string}
    */
   export function readBaseText(dir, base, rel) {
     const env = { ...process.env };
     delete env.GIT_DIR;
     delete env.GIT_WORK_TREE;
     delete env.GIT_INDEX_FILE;
     const spec = `${base}:./${String(rel).split(path.sep).join('/')}`;
     const r = spawnSync('git', ['-C', dir, 'show', spec], { encoding: 'utf8', env, maxBuffer: 64 * 1024 * 1024 });
     return r.status === 0 && typeof r.stdout === 'string' ? r.stdout : '';
   }
   ```
