## 4. `cleargate-cli/.github/workflows/ci.yml`: full text

Action SHAs were resolved with `git ls-remote` on 2026-11-07. Both are lightweight tags (no `^{}` peel line), so the tag SHA is the commit SHA, and both are the newest release.
- `actions/checkout` `refs/tags/v7.0.1` = `refs/tags/v7` = `3d3c42e5aac5ba805825da76410c181273ba90b1`; `action.yml` `runs.using: node24`.
- `actions/setup-node` `refs/tags/v7.1.0` = `refs/tags/v7` = `949feb2413d6458794dcd2491c4babbbce0c15c1`; `runs.using: node24`, `cache: npm` input present.

The gitleaks image `ghcr.io/gitleaks/gitleaks:v8.30.1` has OCI index digest `sha256:c00b6bd0aeb3071cbcb79009cb16a60dd9e0a7c60e2be9ab65d25e6bc8abbb7f`. It is multi-arch: linux/amd64 for CI and linux/arm64 for OrbStack, so one digest serves both. v8.30.1 is the newest gitleaks tag.

```yaml
# cleargate-cli CI (EPIC-061 S7, STORY-061-03).
# Runs the prepublishOnly checks on every pull request and every push to main,
# then scans the full git history for secrets with a digest-pinned gitleaks image.
# Every action is pinned to a full commit SHA; the comment names its release.
name: ci

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

jobs:
  check:
    name: typecheck, build, test, pack, secret scan
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - name: Check out full history
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0
          persist-credentials: false

      - name: Set up Node 24
        uses: actions/setup-node@949feb2413d6458794dcd2491c4babbbce0c15c1 # v7.1.0
        with:
          node-version-file: .nvmrc
          cache: npm

      - name: Install
        run: npm ci

      - name: Typecheck
        run: npm run typecheck

      - name: Build
        run: npm run build

      - name: Test (default tier)
        run: npm test

      - name: Verify pack
        run: node scripts/verify-pack.mjs

      # Same command runs locally from the repo root (Docker or OrbStack).
      - name: Secret scan (gitleaks v8.30.1, full history)
        run: >-
          docker run --rm -v "$PWD:/repo:ro" -w /repo
          ghcr.io/gitleaks/gitleaks:v8.30.1@sha256:c00b6bd0aeb3071cbcb79009cb16a60dd9e0a7c60e2be9ab65d25e6bc8abbb7f
          git --config .gitleaks.toml --log-opts=HEAD --redact --verbose --no-banner --exit-code 1 .
```

Decisions baked in:
- **`node-version-file: .nvmrc`.** `.nvmrc` is tracked and contains `24`, so it is the single source of the Node major.
- **`persist-credentials: false`.** No step pushes, so the token is not left in `.git/config`.
- **`timeout-minutes: 20`.** The suite takes about 2.2 min on Linux. The timeout caps a hung test on private-repo minutes (Q5).
- **`--log-opts=HEAD`.** It scans the checked-out commit's full ancestry, which is what Scenario 3 means by "full history of the story commit". It replaces gitleaks' default `--all`, so the result does not depend on which other refs a checkout happens to hold: locally the owner has unmerged `story/BUG-10x`, `contract/*` and similar branches. On a `pull_request` run, HEAD is the merge ref, so the PR's commits are included. On the probe clone `--all` and `HEAD` scanned the same 468 commits.
- **`--redact`.** It keeps any real secret out of the public Actions log. `--verbose` prints the finding's file and RuleID, which Scenario 4 requires.
- **`:ro` mount.** gitleaks only runs `git log`.
- **The container runs as root with `safe.directory=*` in its global git config** (checked with `docker run --entrypoint sh … id; git config --global --list`). So the runner's uid-1001 checkout does not trip git's dubious-ownership check.
- **Concurrency and caching beyond `cache: npm` are deliberately not added.** They are not in R4.

**Local command, identical to the CI step, run from the cli root:**

# Runs the run-steps of .github/workflows/ci.yml in order inside a node:24 container.

const y=require("js-yaml"),fs=require("fs");
const wf=y.load(fs.readFileSync(".github/workflows/ci.yml","utf8"));

if(runs[0]!=="npm ci"){console.error("first run step is not npm ci");process.exit(1)}
for(const r of runs.slice(1)) console.log(r.replace(/\n/g," "));')
for s in "${STEPS[@]}"; do

done

echo "ALL-STEPS-OK"
