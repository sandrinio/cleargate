## Helper: `test/helpers/scaffold-roots.ts` (extend; path unchanged per Epic rule)

1. Add `export function stageCanonicalScripts(): { root: string; scriptsDir: string; cleanup: () => void }`:
   - `root = fs.realpathSync(fs.mkdtempSync(path.join(os.tmpdir(), 'cg-staged-scripts-')))`
   - `fs.cpSync(canonicalPath('.cleargate/scripts'), path.join(root, '.cleargate', 'scripts'), { recursive: true })`. The tree is 684 KB, 33 entries plus `lib/` and `test/`. None of its `.mjs` files has a bare npm import (verified by grep), so running from tmp without `node_modules` is safe (FLASHCARD #159).
   - `fs.mkdirSync(path.join(root, 'cleargate-cli'))` + `fs.symlinkSync(path.join(CLI_ROOT, 'dist'), path.join(root, 'cleargate-cli', 'dist'), 'dir')`. Create the link even when `dist` is absent; a dangling link behaves like an unbuilt nested layout.
   - `cleanup = () => fs.rmSync(root, { recursive: true, force: true })`. `rmSync` unlinks the symlink and does not follow it. Never write a custom recursive delete that follows links: it would delete the real `dist/`.
   - Add `import * as os from 'node:os'`.
2. Rewrite the header comment lines 10-13 (`Live-side reads (META_ROOT/...) ... CLEARGATE_META_ROOT/META_ROOT directly`). They describe the pre-EPIC-061 state and they match the Scenario-4 grep. New text: live-side reads now live only in `*.integration.node.test.ts` files, which resolve the meta-repo themselves.
