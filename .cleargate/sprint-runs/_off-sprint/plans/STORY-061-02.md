## Rules applied (STORY-061-01 idioms, plus two new ones)

| Rule | Idiom |
|---|---|
| R1 | `canonicalPath('<payload-rel>')` from `../helpers/scaffold-roots.js`. A *live payload copy* (the meta-repo's `.cleargate/{knowledge,templates,scripts}/**` or `.claude/**`) repoints to canonical. Test titles keep their `live`/`live-outer`/`live-root` labels so titles and counts are unchanged (01 precedent). |
| R1-cli | `path.join(CLI_ROOT, ...)` with `CLI_ROOT` imported from `scaffold-roots.js`. A file that already defines a local `CLI_ROOT`/`CLEARGATE_CLI_ROOT` keeps it and does not import it. |
| R2-seam | Spawn canonical in place. The named env/arg seam confines every write to a tmpdir. |
| R2-copy | `stageCanonicalScripts()` (top-level `before`/`after`). `CLEARGATE_REPO_ROOT` stays the test's own fixture root and is never `staged.root`. |
| R3-extract | Move named tests verbatim (same `describe` path and title) to `<dir>/<stem>.live.integration.node.test.ts`, where `<stem>` = source name minus `.node.test.ts` and minus `.red`. |
| R3-whole | `git mv` to `*.integration.node.test.ts` (keep `.red`), insert `// @cleargate-tier: integration` as line 1, then `git add` the new path again (FLASHCARD 2026-10-04 #close #git). |
| **R3-split** (new, OD-5) | For a test that mixes a meta-repo leg (live read or live/canonical byte-parity) with cli-subject assertions: R3-extract the original verbatim, AND add one default-tier test with a new title containing only the cli-subject assertions. | R4 (siblings only) | `const META_ROOT = process.env.CLEARGATE_META_ROOT ?? path.resolve(CLI_ROOT, '..');` |
| **R6-fixture** (new) | A tmpdir or committed `test/fixtures/` input replaces a read or a spawn against the real corpus. |
