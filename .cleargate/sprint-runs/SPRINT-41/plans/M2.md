**Contract — `src/hosts/types.ts` (Developer implements exactly this):**
```ts
export type HostName = 'claude' | 'codex' | 'copilot';

export interface InstallCtx {
  readonly cwd: string;          // target repo root
  readonly payloadDir: string;   // flat composed payload (core + claude): InitOptions.payloadDir | --from-source temp view | npm default
  readonly pinVersion: string;   // init passes `pinVersion ?? 'latest'`, exactly as Step 5b does today (init.ts:431)
  readonly force: boolean;
  readonly stdout: (s: string) => void;
  readonly stderr: (s: string) => void;
}
export interface RemoveCtx {
  readonly cwd: string;
  readonly stdout: (s: string) => void;
  readonly stderr: (s: string) => void;
}
export interface RemoveReport { readonly removed: readonly string[]; }

export interface HostAdapter {
  readonly name: HostName;
  /** Install-relative POSIX roots copied verbatim from the payload and owned exclusively by this host.
   *  No leading '/', no '..' segment, no trailing '/', non-empty. */
  ownedRoots(): readonly string[];
  /** Roots copied only when a declaring host is selected; owned by core in the manifest (e.g. Codex/Copilot `.agents`). Claude: []. */
  sharedRoots(): readonly string[];
  /** Files this host edits surgically (bounded block / merge / registration). No lifecycle command deletes one wholesale. */
  surgeryTargets(): readonly string[];
  /** Post-copy surgery: instruction bounded block, hook-config merge, MCP registration. */
  install(ctx: InstallCtx): Promise<void>;
  /** Inverse of install's surgery (uninstall, `host remove`): strips ClearGate-owned content only. */
  remove(ctx: RemoveCtx): Promise<RemoveReport>;
}
```

**Why this shape (the Codex sketch, story §1.5 risk 2):**

### STORY-058-04 — `cleargate init --host` selector parsing and profile expansion

**Coupling:**
- Consumes -03's registry, `ownedRoots()` and `sharedRoots()`.
- `cli.ts` and `registry.ts` are shared with -05 (M3, order 04 → 05); `init.ts` with -06; `copy-payload.ts` with -10 (codex payload source).

**Semantics (decided under the owner's autonomy directive — orchestrator amends §1.2 and the Gherkin; text below):**
- **Accepted values** are the hosts registered in `defaultHostRegistry`, plus the profiles `portable` and `all`, both derived from `names()`:
  - `all` = every registered host
  - `portable` = every registered host except `claude` (the story's own §3.2 rule)
- Consequences:
  - at -04: `all` = {claude}, and `portable` fails with "matches no registered host"
  - after -10: `all` = {claude, codex}, `portable` = {codex}
  - `copilot` is rejected as unknown until its adapter registers
- Rationale: accepting a host with no adapter either installs nothing (the "installed nothing on purpose" failure -04 §1.4 rejects) or crashes. Rule 3 is met in full when the Copilot adapter lands. This is an honest interpretation for the SPRINT-41 slice (orchestrator logs a Mid-Sprint Amendment).
- **Pipeline:** each raw occurrence → split on `,` → `trim` → `toLowerCase` → an empty token is an error (covers `--host ""`, `--host "claude,"`, `--host "  "`) → a profile expands (an empty expansion is an error) → otherwise the token must be a registered name → dedupe.
- **Result order** is registry order, whatever order the flags came in. The first failing token in argv order is the one reported.
- **Absent** (`undefined`) or `[]` → `DEFAULT_HOSTS = ['claude']`. Commander never produces `[]`; programmatic callers may.
- **Error exit is 2**, the same as the `--from-source` `ScaffoldSourceError` path. The check runs **before Step 1**, so nothing is written, not even the write probe.
- **Stdout:** no new line for any valid selection. `--host claude` output equals no-flag output.
