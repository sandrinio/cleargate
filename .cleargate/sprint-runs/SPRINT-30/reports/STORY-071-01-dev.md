## Hook Script Notes

The hook uses `jq` for JSON parsing. If `jq` is absent, the hook silently exits 0 (graceful degrade). The CLAUDE_PROJECT_DIR env var provides the project root, falling back to `.` for test fixture compatibility. Dispatch-marker agent extraction uses `ls -t ... | head -1 | xargs jq -r .agent` with a fallback to `"unknown"` — this is inherently racy (no dispatch marker exists for non-agent AskUserQuestion calls) and was accepted as a v1 design decision in CR-071 Open Question #1.
