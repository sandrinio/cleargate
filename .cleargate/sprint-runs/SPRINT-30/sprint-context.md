## Cross-Cutting Rules

Sprint-wide architecture rules every M1 story must honour. Derived from the M1 items' shared concerns (init.ts surface ownership, three-site dogfood-mirror discipline, identity/membership state-machine invariants, schema-version stability, pre-member default).

1. **`cleargate-cli/src/commands/init.ts` is a shared surface this milestone.** Three M1 stories edit it (STORY-068-01 line 452, STORY-069-01 post-Done banner, BUG-031 identity/state resolver). Merge order is fixed: STORY-068-01 → STORY-069-01 → BUG-031. Do not parallel-merge — sequential serialization is mandatory because the file is small and rebases are cheap.
2. **Three-site dogfood-mirror discipline applies to every payload edit.** Canonical (`cleargate-planning/.gitignore`, `cleargate-planning/CLAUDE.md`) → npm payload (`cleargate-cli/templates/cleargate-planning/**`, regenerated by `npm run prebuild`) → live `/.claude/` (gitignored, hand-port or `cleargate init` against meta-repo). STORY-072-01 is the M1 story that flexes this rule. Forgetting any leg leaves a stale install or stale agent runtime.
3. **Identity is global; project_id is per-repo.** Per CR-011 + BUG-031 fix: participant email may be inferred from git config user.email globally, but `~/.cleargate/auth.json` membership tokens must NOT cause a fresh repo to report `state: member`. Fresh repo with no per-repo join → `state: pre-member` regardless of global token presence. The fix discriminator is the WORKING DIRECTORY, not the host.
4. **Tests touch real processes, real tmpdirs, real `git init`.** Every M1 story whose acceptance Gherkin says "fresh repo" or "fresh tmpdir" must drive its tests via `node:child_process.spawnSync` against a `mkdtempSync` fixture that has been `git init -b main`'d. No mocked `fs`, no mocked spawn. Per global policy (CLAUDE.md "Real infra, no mocks").
5. **node:test only. File naming `*.node.test.ts`.** Per EPIC-028 closure 2026-05-18 — vitest is eliminated. New tests use `tsx --test` runner. Existing init test file is `cleargate-cli/test/commands/init.node.test.ts` (already correctly named).
6. **Readiness-gate path-extractor regex tightens mid-sprint (STORY-073-01).** Stories merged AFTER STORY-073-01 lands MUST cite §Existing Surfaces paths with at least one `/` separator; root-level files use `./CLAUDE.md` form. Stories merged BEFORE STORY-073-01 land under the permissive rule. M1 wave plan lands STORY-073-01 in Wave 0 to neutralize this drift across the rest of M1.
