## 4. New code to create — `provision_worktree_config.sh` [Class 3, LIVE ON MERGE]

**Args:** `provision_worktree_config.sh <worktree-path> [--mode symlink|copy]`. Default mode from `config.yml worktree.provision_mode`, overridable by flag.
