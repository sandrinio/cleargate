# BUG-089: Both blocking PreToolUse gates exit 1, which Claude Code treats as non-blocking — the planning-first gate and the flashcard write-gate are fail-open

**Status:** Completed · **Sprint:** none · **Gate:** pass · **Severity:** P1-High

## Anomaly
**Expected Behavior:** The two PreToolUse gates that ClearGate documents as *always enforced* actually stop the tool call they are wired to.
`pre-edit-gate.sh` (matcher `Edit|Write`) should refuse an edit to a file no approved story covers when the planning-first gate is in enforce mode and the existing active-sprint bypass does not apply. Its default warning mode and active-sprint bypass are not changed by this repair.
